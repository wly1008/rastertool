## 重投影``reproject``、重采样``resampling``

- ``reproject``: ``rasterio.reproject``工具化，可在文件层面操作。
- ``resampling``: 即不做投影变化的``reproject``调用

## 裁剪``clip``

- 算法思路类于``rasterio.rio.clip``，以栅格或bounds裁剪栅格，支持crop参数，以有效值位置提取栅格。
- 分窗口``clip``位于``tast.unify.clip_resampling.clip``, 后续做番检测再将之移出，另同位置的分窗口重采样未考虑窗口衔接处的邻域计算，不在乎误差可酌情使用，既用分窗口，一般为超大型栅格，确可忽略此误差。

## 统一地理空间属性``unify``

- 基于本库``clip``与``reproject``函数实现栅格文件间的地理空间属性完全一致--空间参考、分辨率、空间范围。以使得项目栅格矩阵像元在地理空间上一一对应，是各栅格处理分析的基础工作。
- ``unify``以拼接模块实现，生成中间文件以妥协内存与速度问题。后续将实现矩阵为中间数据，暂待。
- 一般处理流程为``reproject``(内置resampling参数)-->clip，
- 如待处理栅格过大无法读取，请使用Double(``clip``-->``reproject-``->``clip``)或Triple(``clip``-->``reproject``-->``resampling-``->``clip``)参数
- 如目标范围依旧过大，请使用分窗口裁剪，分窗口重采样考虑误差，分窗口投影暂未实现。


## 按距离权重合并``merge_distance_weights``

- 参考``rasterio.merge``，实现重叠区域按距离加权平均
- 请保证输入栅格空间参考相同
- 加权方法为插值法的变体，距离参数由与源数据距离d_origin换为重叠区域dmax与像元离边缘距离差值d_overlap_max-d_edge, 由于W可自定义，按其物理意义该参数被控制于正值或非负值。
- 内置加权方法:
  - ``Gaussian``高斯距离衰减法:

    d_max = W            
    ω_A = e^((d_max - d_A )^2 / (-2σ^2 ))       
    ω_B = e^((d_max - d_B )^2 / (-2σ^2 ))       
    V = (A * ω_A + B * ω_B) / (ω_A + ω_B)  
    其中：  
    d：像元至边界的距离  
    dmax: 像元至边界的最大距离  
    W: 叠置区宽度，为两倍的缓冲区宽度  
    ω：距离对应的权重  
    σ：标准差，控制衰减速度（越小衰减越快），经验估计W=3σ~5σ  
    V：A,B叠置区域加权值  
    
  - ``IDW``反距离权重法
    
    d_max = W             
    ω_A = 1 / (dmax - d_A)^k      
    ω_B = 1 / (dmax - d_A)^K  
    V = (A * ω_A + B * ω_B)/(ω_A + ω_B)

    其中:
    d_A、d_B：像元分别到 A、B 影像边界的距离
    d_max：像元到边界的最大距离
    W：叠置区宽度
    ω_A、ω_B：对应影像的距离权重
    k：距离衰减指数（幂指数），控制权重随距离增加的衰减速度

  - ``Voronoi`` 最近距离赋值法
    
    V = SA * A + SB * B  
    SA, SB = selectmax(d_A, d_B)

    其中:
    SA, SB: 是否选取A、B，是为1，否为0







## 邻域统计 `focaltool`

- `focaltool` 实现文件层面的 **focal（邻域）统计分析**，以每个像元为中心，在给定半径的窗口内对有效像元进行统计计算。
- 算法主要基于 `scipy.ndimage` 的卷积与滤波函数，并针对常用统计量做了缓存与性能优化。
- 统计过程中 **NoData 像元不参与计算**，内部通过 `valid_mask` 控制。
- 支持是否剔除中心像元（`deleted=True`），可用于邻域对比、空间自相关等分析场景。

### 支持的内置统计量

通过 `stat` 参数指定，内置统计函数统一注册于 `FOCAL_STATS`：

- `count`：邻域内有效像元数量
- `sum`：邻域和
- `mean`：邻域均值
- `min`：邻域最小值
- `max`：邻域最大值
- `var`：邻域方差（总体方差，除以 N）
- `std`：邻域标准差
- `perc`：邻域分位数（由 `q` 参数指定）
- `median`：邻域中位数（等价于 `perc, q=50`）

同时支持 **自定义统计函数**，函数签名需与内置 focal 函数保持一致。

### 邻域窗口与核

- 邻域窗口大小由 `radius` 控制，实际核尺寸为
   `(2 * radius + 1) × (2 * radius + 1)`
- 使用 `create_kernel` 生成卷积核：
  - `deleted=False`：中心像元参与统计（默认）
  - `deleted=True`：中心像元不参与统计

### 边界与掩膜处理

- 边界处理方式通过 `mode` 参数直接传递给 `scipy.ndimage`，如：
   `reflect`、`nearest`、`constant` 等
- `crop` 参数用于控制输出 NoData 行为：
  - `True`：输出 mask 与输入一致，不扩展 NoData
  - `False`：邻域内无有效值（count=0）的位置输出为 NoData

### 性能与实现说明

- 内部使用 `cache` 机制，避免 `count`、`sum` 等中间量重复计算
- `var` / `std` 使用滑窗一阶、二阶矩方式实现，时间复杂度为 O(1)
- 分位数统计默认使用 `generic_filter`，保证数值正确性；保留了快速实现版本，暂未启用





## 异常值剔除 `remove_outliers`

- `remove_outliers` 用于对栅格数据进行 **异常值（outliers）剔除处理**，将超出阈值范围的像元置为 `nodata`。
- 支持整幅栅格统一处理，亦支持 **按区域（分区栅格）独立剔除**，各区域阈值互不影响。
- 仅对有效像元参与统计，原有 `nodata` 不参与阈值计算，也不会被误改。

### 支持的异常值判定方法

通过 `method` 参数指定，内置方法注册于 `MERGE_METHODS`：

- `std`：基于均值 ± N 倍标准差
  - `method_arg`：标准差倍数（如 3，默认 3）
- `perc`：基于百分位阈值
  - `method_arg`：百分位数（如 5，等价于 [5, 95]，或直接传 (5, 95)）
- `value`：直接指定有效值范围
  - `method_arg`： (min, max)，该方法下为必填项
- `callable`：自定义阈值函数，需返回 `(q_low, q_high)`

### 分区剔除（区域独立阈值）

- 通过 `dst_in` 参数提供分区栅格或数组：
  - 每个 **唯一值区域** 独立计算阈值
  - 区域之间互不影响
- `drop` 参数控制未参与分区的像元行为：
  - `False`：保留原值（默认）
  - `True`：保持为 `nodata`

### 处理流程说明

- 内部流程为：
  1. 提取有效像元
  2. 按方法计算阈值范围
  3. 超出阈值范围的像元置为 `nodata`
- 通过 `np.copyto` 实现原地写入，避免不必要的数据拷贝
- 支持直接写出文件，或返回内存数组与 profile

### 参数补充说明

- `nodata` / `dtype` / `compress` 行为与本库其他工具一致
- `update_stats` 控制写出时是否更新栅格统计信息
- 当 `out_path=None` 时，返回 `(array, profile)`
